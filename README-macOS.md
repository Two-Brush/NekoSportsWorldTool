# Mac 本地安装包使用说明

适用于 Apple Silicon Mac（M1、M2、M3、M4 等）。无需安装开发工具。

## 1. 把安装包传到 Mac

将本地的 `NekoSportsWorldTool-macos-arm64-app.zip` 复制到 Mac，例如放到“下载”文件夹。只需要这个 ZIP，旁边的 `.tar.gz` 不用解压。

## 2. 解压并安装

1. 双击 ZIP，得到 `NekoSportsWorldTool.app`。
2. 把这个 `.app` 拖到 Finder 的“应用程序”文件夹。
3. 在“应用程序”中双击打开。

## 3. 如果首次打开被拦截

安装包未经过 Apple 公证，首次运行可能提示“无法验证开发者”。确认安装包来自本仓库后：

1. 先尝试打开应用，再关闭拦截提示。
2. 打开“系统设置 → 隐私与安全性”。
3. 找到该应用的拦截提示，点击“仍要打开”，按提示确认。

不要全局关闭系统安全保护。若提示“应用已损坏”，先重新下载并解压完整安装包。

## 4. 打开后怎么用

1. 先到“关于”页，将“启动时检查更新”设为“关闭”，避免自动更新覆盖当前版本。
2. 在“账号与登录”区域填写账号、密码，点击“登录”。
3. 按页面提示确认学校、校区和定位信息，修改后保存。
4. 点击顶部的“运动记录”“数据”“路网”等页面使用对应功能。

## 更新与数据

更新时先退出应用，再用新版 ZIP 解压出的完整 `.app` 替换“应用程序”中的旧版。

配置和登录数据保存在 `~/Library/Application Support/NekoSportsWorldTool/`，正常替换 `.app` 会保留数据。该目录包含隐私信息，请勿发送给他人。
